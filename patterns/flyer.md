# Flyer Pattern V1

## 対象

A4前後の一枚チラシ、案内、募集、周知物を対象にします。

## 制作前に固定するもの

最初に、目的、対象者、最重要メッセージ、必須情報、行動導線を固定します。

文章とデザインを同時に大きく変更しません。

## 基本構造

```text
1. Short catch / context
2. Main message
3. Supporting explanation
4. 2〜4個の具体例または要点
5. Action / QR / contact
6. Necessary note
```

全案件で6要素を必須にはせず、不要な要素は削除します。

## レイアウト

最初に見る場所を一つにします。

主見出しの周囲には十分な余白を確保します。

複数の囲み、吹き出し、色面を同時に増やしません。

QRコードは他の情報から分離し、周囲の余白を確保します。

QRが主要な行動導線の場合は、QRだけを孤立させず、読み取り後に何をするかを短く示す文言と一つの行動ブロックとして扱います。

注意書きは必要性を保ちつつ、本文全体を圧迫しない位置へ置きます。

## イラスト

意味のある場面だけを補助的に描きます。

イラストを置くために本文やQR導線を縮小しません。

## 制作フロー

```text
Human Definition / Scope Lock
↓
Content Structure / Content Lock
↓
Concept Sketch（比較が必要な場合）
↓
Human Direction Selection
↓
Draft
↓
Accessibility Baseline Check
↓
Visual Review
↓
Correction
↓
Human Visual Acceptance
↓
Output Route Selection
↓
Preflight
↓
Human Output GO
↓
Print / Publish
```

`Human Visual Acceptance` と `Human Output GO` は別ゲートです。

見た目が承認されても、QR、仕上がりサイズ、印刷条件、誤字などの出力確認が終わるまでは印刷または公開しません。

チラシやポスターでは、編集可能性を残したい場合はCanva等を経由し、直接PDFで成立する場合は不要なツールを増やしません。

出力前の確認には `review/output-preflight.md` を使います。
