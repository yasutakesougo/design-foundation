# Poster Prompt（候補）

- Status: 候補。Prompt V1ではない
- Source: ひとこと掲示 V3
- Date: 2026-09-08

Human Visual Acceptance、実寸印刷確認、実試行で少なくとも一度成立するまで `prompts/` へ昇格しません。

```text
目的と対象者を最初に確認し、最重要メッセージを一つに絞ってください。

読む量を減らし、タイトル → 具体例（最大3件） → 大きなQR → 最短の行動説明 → 最低限の注意、の順で完結させてください。

深い緑系を基調にし、白〜生成りの背景にしてください。黄〜オレンジは少量だけ使い、オレンジを主色にしないでください。
手書きの気配は紙の質感とイラストで出し、見出しに装飾書体を使わないでください。
親しみやすくても幼い印象にはしないでください。
福祉らしさを記号的に強調しないでください。

QRを中央付近の主役にしてください。
イラストは1場面までとし、現場の日常で一瞬立ち止まっている雰囲気がある場合だけ補助的に使ってください。
「AI」「システム」「投稿フォーム」は前面に出さないでください。
広報ネタ募集・改善提案募集に見せないでください。

未確定の運用条件（完全匿名、閲覧範囲、保存日数など）を掲示面で約束しないでください。
印刷QRには固定入口だけを使い、期限付きPreview URLを使わないでください。

色だけで意味を伝えないでください。
本文を情報量の都合で過度に小さくしないでください。
QRコードの周囲に十分な余白を確保してください。

文章とデザインを同時に大きく変更しないでください。
構成の方向性が未確定なら、完成案へ進む前にConcept Sketchで比較してください。

最後にvisual-review.mdとaccessibility.mdを使って確認してください。
Human Visual Acceptanceの前に自動で最終採用を決めないでください。
Human Visual Acceptance後も本印刷・正式掲示へ直行しないでください。
出力時はroot README.mdの基本フローとreview/output-preflight.mdに接続し、Output Route Selection → Preflight → Human Output GO → Print / Publish の順を守ってください。
```
