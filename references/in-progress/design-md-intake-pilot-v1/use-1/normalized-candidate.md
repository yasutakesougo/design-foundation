## Project purpose

初見職員へ、広報部会を「発信を増やす会」ではなく、日常の小さな観察を拾う活動として伝えます。

## Audience

法人内職員。

広報に詳しくない人でも短時間で理解できる構成にします。

## Visual tone

- 静か
- 温かい
- 観察的
- 大人向け
- 少し人の手触り
- 軽い非対称

## Typography roles

- Title: 左揃え、太め、最大2行。
- Heading: titleより明確に弱くする。
- Body: 日本語sans-serif、A4実寸優先。
- Note: 本文より1段階小さくするが読めるサイズを維持。
- Avoid: novelty display font、極端な手書きフォント、細すぎる文字。

## Color roles

- Primary: deep green。
- Background: warm off-white。
- Accent: muted yellowを少量。
- Secondary surface: pale mintを必要時のみ。
- Text: near-black green。
- Avoid: orange primary、gradient、強い多色accent。

## Spacing / rhythm

- Title zoneは広めに取る。
- Supporting ideaからexamplesへ中程度の間を置く。
- Examples同士はまとまりを持たせる。
- 全区間を同じ間隔にしない。

## Composition principles

- First focal point: main concept。
- Secondary focal point: 3 examples。
- Reading flow: top-left → supporting idea → examples → closing。
- Main text: left aligned。
- Examples: 微小なずれを許容する。
- Three examplesを完全に同一のUIカードへしない。

## Illustration / photography role

- 0〜1 scene。
- 人が日常を見ている気配を補助する場合だけ使う。
- adult / neutral / no stereotype。
- title、examples、closingより弱くする。

## Accessibility constraints

- body copyはA4実寸で再確認する。
- text/background contrastをローカルで再確認する。
- yellowに可読性を依存しない。
- colorだけで意味を区別しない。

Accessibility PASSは未判定です。

## Anti-patterns / avoid list

- rounded SaaS card repetition
- all-centered composition
- equal spacing everywhere
- decorative icon repetition
- large character illustration
- gradient
- high color count
- welfare stereotype pictograms

## Project-specific items

- examplesの微小rotation / offset。
- warm off-whiteとmuted yellowの具体的な色値。
- 左揃えを今回のHuman intentへ合わせて採用する判断。

## Normalized candidate rules

- Titleを左上の唯一のfirst focal pointにする。
- 深い緑を主軸にする。
- 背景はwarm off-white。
- muted yellowはtitleの小さなmarker accentだけにする。
- 本文は左揃え。
- 三つのexamplesは同一UIカードにせず、紙片のような微小なずれを許容する。
- 余白はtitle zone / example cluster / closingで異なるリズムにする。
- 人物を使う場合は1scene以下で、成人・中立・補助役にする。
- Web UI、均等カード、中央揃え、グラデーション、福祉ピクトを避ける。
