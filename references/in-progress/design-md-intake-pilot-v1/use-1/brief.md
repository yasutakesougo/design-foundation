# DESIGN-MD-INTAKE-PILOT-USE-1 — Shared Brief

## Purpose

初見の職員が、広報部会の考え方をA4縦1枚で短時間に理解できるようにします。

発信本数を増やすことではなく、現場にすでにある小さな気づきを拾う活動だと伝えます。

## Content Authority

### Main concept

`障害福祉の日常を、社会に翻訳する。`

### Supporting idea

`広報のために特別な出来事を増やすのではなく、すでにある日常の見方を拾う。`

### Examples

- `待った3分`
- `今日は声をかけなかった`
- `いつもの場所`

### Closing

`必要なものだけ、少し先を考える。何もしないことも判断です。`

## Audience

法人内の職員。

広報業務に詳しくない職員も含みます。

## Medium

A4 portrait / one page.

印刷またはPDF閲覧を想定します。

## Foundation constraints

- 内容理解を装飾より優先する。
- 最初に見る場所を一つにする。
- 深い緑を主軸にする。
- 色数を増やしすぎない。
- 親しみやすさと幼さを混同しない。
- 福祉らしさを記号化しない。
- 装飾のためだけの装飾を追加しない。
- 余白で情報の関係を整理する。
- イラストのために本文を縮小しない。

## Human visual intent

`静か / 温かい / 少し人の手触り / 大人向け / 読みやすい / 小綺麗にまとめすぎない`

## Avoid

- Web UI / SaaS card layout
- 子ども向け
- 啓発ポスター調
- 色数過多
- 装飾過多
- AI分析感
- 福祉を象徴する記号の多用

## A/B rule

Route AとRoute Bは、このContent Authorityを同一に保ちます。

文言差ではなく、未指定のデザイン判断がどの程度揃うかを比較します。
