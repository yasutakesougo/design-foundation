## Project purpose

広報部会を「発信本数を増やす会」と誤解させず、日常の小さな観察を拾う活動として初見職員へ伝えます。

## Audience

広報に詳しくない職員を含む法人内職員。

短時間で意味をつかめることを優先します。

## Visual tone

`quiet / warm / observant / adult / human / lightly irregular`

## Typography roles

- Title: 左揃え。大きく、太め。2行まで。
- Heading: medium weight。
- Body: 読みやすい日本語sans-serif。
- Note / caution: 本文より1段階小さくするが、実寸A4で読めること。
- Avoid: display font、極端な手書きフォント、細すぎるウェイト。

## Color roles

- Primary: deep green `#234B3E`
- Background: warm off-white `#F6F2E8`
- Accent: muted yellow `#E2C45A`
- Text: near-black green `#24352F`
- Secondary paper tone: pale mint `#E9F0E8`
- Avoid: vivid orange as primary、gradient、5色以上の強いaccent。

## Spacing / rhythm

- Large gap: title zoneとexamplesの間。
- Medium gap: supporting ideaとexamplesの間。
- Compact rhythm: example内。
- Density rule: 余白を均等割りせず、title zoneは広く、examplesは少しまとまりを持たせる。

## Composition principles

- First focal point: `障害福祉の日常を、社会に翻訳する。`
- Secondary focal point: 3つの小さな例。
- Reading flow: top-left → supporting idea → examples → closing。
- Alignment / asymmetry rule: 本文は左揃え。examplesは2〜5度以内の微小なずれを許容する。
- Repetition rule: 三つの例を完全に同一のUIカードにしない。

## Illustration / photography role

- Purpose: 「人が見ていた日常」を感じさせる補助。
- Amount: 0〜1 scene。
- Subject treatment: adult / workplace-neutral / no disability stereotype。
- Must not overpower: title、examples、closing。
- Avoid: mascot、childlike proportions、福祉記号、装飾目的の人物。

## Accessibility constraints

- body copyはA4実寸で読めること。
- titleとbackground、bodyとbackgroundのコントラストをローカルで再確認する。
- accent yellowに本文可読性を依存しない。
- colorだけで意味を区別しない。

この記述自体はAccessibility PASS evidenceではありません。

## Anti-patterns / avoid list

- SaaS dashboardのような角丸カード反復
- 全要素の中央揃え
- 均等な縦間隔だけで構成する
- 装飾アイコンの反復
- 大きな人物イラスト
- グラデーション
- 色数を増やして温かさを表現する
- 福祉を直接象徴するピクトグラム

## Rationale

Human briefにある `静か` と `少し人の手触り` を同時に成立させるため、情報自体は左揃えと余白で安定させ、examplesだけに小さな位置差を許容します。

温かさは色数ではなく、warm off-white、muted yellow、紙のような面、微小な非対称で表現します。
