## Operational use before Promotion

The candidate may be used only as a project-level working contract after the applicable project authority allows it.

A successful implementation or one successful project does not establish a general Foundation rule.

Before any Promotion proposal, collect real operational evidence from materially different creative cases when they naturally occur.

Evidence should test whether the candidate:

- prevents cross-reference contamination;
- reduces regression during correction;
- prevents rejected-direction leakage;
- reduces waste before multi-asset scaling;
- adds acceptable rather than excessive process overhead.

Do not create artificial projects merely to produce Promotion evidence.
