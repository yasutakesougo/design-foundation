# Notion Short Spec

## 位置づけ

これはNotionなど人向け説明面へ転記するための短縮版です。

Canonical AuthorityはGitHubのHITOKOTO PERSON LINE STYLE V1です。

## ひとことで言うと

緑のサインペンでさっと描いたような、静かで親しみのある人物線画です。

## 使い方

人物線画は文章やQRの主役にはしません。

人の気配や、見る・考える・書くなどの小さな動作を補います。

## 見た目

- 単色の緑線画
- 白または透明背景
- 塗りなし
- 影なし
- 胸上が基本
- 少しだけ揺れた手描き線
- 顔は点や短線で最小限
- 髪は外形と少数の線だけ
- 穏やかな表情
- 幼くしない
- マスコット化しない
- 福祉記号化しない

## 色

Production SVGは `currentColor` を使います。

利用面ではDesign FoundationのPrimary色を使います。

Pilot開始時点では `#234E3F` です。

## 10の動作

1. メモを取る
2. 考える
3. 眺める
4. 聞く
5. うなずく
6. 読む
7. 話す
8. 見守る
9. 気づく
10. 待つ

動作は電球、疑問符、時計などの説明記号ではなく、視線、姿勢、手、小物で示します。

## SVG

```text
viewBox = 0 0 512 512
stroke = currentColor
stroke-width = 8
linecap / linejoin = round
fill = none
path = 45以下
```

## Pilot

最初は次の3点だけを確認します。

- メモを取る人
- 考える人
- 眺める人

3点が同じシリーズとして成立してから残り7点を検討します。

## 判断基準

迷ったら足すより減らします。

かわいさより静けさを優先します。

説明記号より人物の姿勢を優先します。

必要な意味をイラストだけに依存させません。
