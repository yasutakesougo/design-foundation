# Behavior Prompts V1

## 使い方

このファイルは、HITOKOTO PERSON LINE STYLE V1の人物線画を生成するときの指示テンプレートです。

生成結果は、そのまま仕様適合とは扱いません。

SVG化後に `svg-path-spec.md` と `review-checklist.md` で確認します。

## 共通スタイル

各プロンプトの先頭に次を含めます。

```text
「ひとこと返し」用の人物線画を作成する。
単色の緑線画にする。
白背景または透明背景にする。
胸上の人物にする。
塗り、影、グラデーションは使わない。
線幅は均一寄りにし、少しだけ手描きの揺れを残す。
顔は点または短線の目、短い鼻線、小さな口で最小限に描く。
髪は外形と少数の内部線だけで示す。
幼くしない。
かわいすぎるキャラクターやマスコットにしない。
福祉を象徴する記号的人物にしない。
装飾を増やさない。
文章、投稿内容、QR、行動導線より目立たせない。
```

色は生成後のProduction SVGでは固定せず、`currentColor` へ正規化します。

## 01 note-taking / メモを取る

```text
小さなメモ帳を片手に持ち、もう片方の手でペンを使ってメモを取っている人物を描く。
視線は少し手元に向ける。
表情は落ち着いたものにする。
メモ帳の中に文字を書かない。
手と指は動作がわかる最低限の線にする。
メモ帳やペンを人物より強く見せない。
```

## 02 thinking / 考える

```text
片手を軽くあごまたは頬に添えて考えている人物を描く。
顔を少し傾ける。
視線は少し上または横に向ける。
困っている顔ではなく、静かに考えている表情にする。
電球、疑問符、吹き出し、頭上の記号を使わない。
```

## 03 looking / 眺める

```text
人物を少し横向きにする。
視線を遠くへ向け、何かを静かに眺めている状態を描く。
軽い笑顔または穏やかな無表情にする。
眺めている対象や背景は描かない。
顔の向きと視線だけで動作を表現する。
```

## 04 listening / 聞く

```text
少し横を向き、誰かの話を静かに聞いている人物を描く。
首をわずかに傾けてもよい。
口は閉じる。
視線は話し手がいる方向へ向ける。
耳を大きく描くなどの説明的な誇張はしない。
音符、吹き出し、会話記号を使わない。
```

## 05 nodding / うなずく

```text
人物の頭を少し下げ、静かにうなずいている状態を描く。
表情は穏やかにする。
目を短い曲線にしてもよい。
強い笑顔にはしない。
動き線や効果線を使わず、頭と視線の角度で動作を示す。
```

## 06 reading / 読む

```text
小さな紙または本を持って読んでいる人物を描く。
視線は紙面に向ける。
本や紙に文字を描かない。
手や指は簡略化する。
本を人物より大きく見せない。
静かに読んでいる雰囲気にする。
```

## 07 speaking / 話す

```text
誰かへ短く話しかけている人物を描く。
顔を少し横へ向ける。
口は少しだけ開いてもよい。
大きな口や誇張した表情にしない。
吹き出し、文字、音符を描かない。
会話の途中にいる自然な人物として描く。
```

## 08 watching / 見守る

```text
少し離れた対象を静かに見守っている人物を描く。
体と顔をわずかに横へ向ける。
手を前へ差し出して介助しているような表現にしない。
保護者、支援者、医療者を示す記号を使わない。
穏やかな視線と姿勢だけで見守りを表現する。
```

## 09 noticing / 気づく

```text
何かにふと気づいた瞬間の人物を描く。
視線を少し横へ動かす。
眉や目の位置をわずかに変えて気づきを示す。
驚いた大きな目にしない。
感嘆符、電球、放射線を使わない。
小さな表情変化だけで動作を表現する。
```

## 10 waiting / 待つ

```text
静かに待っている人物を描く。
正面または少し横向きにする。
表情は穏やかにする。
何もしていないように見える程度の静かな姿勢にする。
時計、腕時計、砂時計、待機記号を描かない。
時間を置いている感じを姿勢と視線だけで表現する。
```

## 動作の分離基準

`looking` は、対象を特定せず遠くへ視線を置く状態です。

`watching` は、対象との距離を保ちながら関心を向け続ける状態です。

`noticing` は、視線や表情が変わる瞬間です。

この3つを同じポーズへ収束させません。

## 量産時のルール

同じ人物を髪型だけ変えて10体にしません。

顔の情報量は揃えます。

線密度は揃えます。

動作ごとに必要な手、小物、視線だけを追加します。

1回の生成結果だけでシリーズ品質を確定しません。
