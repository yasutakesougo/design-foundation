# Rejected References

採用しなかった案のうち、同じ失敗を繰り返さないために価値があるものを記録します。

単に「好みではない」で終わらせず、どの判断が問題だったかを残します。

## 記録テンプレート

```markdown
## <Reference name>

- Date:
- Medium:
- Source:
- Decision: REJECT
- Anti-pattern: <必要な場合のみ>

### 気になった点

- 

### 再発を避けたい判断

- 

### 条件が変われば使える点

- 
```

Anti-pattern名は、同じ失敗の再発防止に役立つ場合だけ付けます。

外部カタログを一括コピーせず、このRepositoryで実際に確認した失敗だけを蓄積します。

不採用事例を禁止事項の無制限な追加に使いません。
