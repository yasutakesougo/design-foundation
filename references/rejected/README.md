# Rejected References

採用しなかった案のうち、同じ失敗を繰り返さないために価値があるものを記録します。

単に「好みではない」で終わらせず、どの判断が問題だったかを残します。

## 記録テンプレート

```markdown
## <Reference name>

- Date:
- Medium:
- Source:
- Decision: REJECT
- Anti-pattern: <必要な場合のみ>

### 気になった点

- 

### 再発を避けたい判断

- 

### 条件が変われば使える点

- 
```

## CuteGuideCharacter

- Date: 2026-09-08
- Medium: 掲示補助イラスト
- Source: ひとこと掲示 V3 検討中の生成案
- Decision: REJECT
- Anti-pattern: CuteGuideCharacter

### 気になった点

- 大きな目と笑顔が強く、かわいすぎるアニメキャラクターに見える。
- こちらへ案内する存在に見え、日常の観察者より返答者・案内役に寄る。

### 再発を避けたい判断

- 人物を導線の主役にしない。
- デフォルメと満面の笑顔で親しみやすさを作らない。
- 名札、ストラップ、手のひらを向けたポーズなど、職種や誘導を連想させる記号を置かない。

### 条件が変われば使える点

- 水彩と生成り紙の質感自体は、観察者の方向でも使える。

## OperationalPromiseOnPrint

- Date: 2026-09-08
- Medium: 掲示
- Source: ひとこと掲示 V3 運用境界
- Decision: REJECT
- Anti-pattern: OperationalPromiseOnPrint

### 気になった点

- 保存期間、閲覧範囲、匿名の程度など、実試行前にexact値が未確定の事項を印刷面で約束すると、後から撤回できない。

### 再発を避けたい判断

- 未確定の運用条件をチラシ・掲示で約束しない。
- 期限付きPreview URLを印刷QRに使わない。
- 本印刷の可否は、デザイン完成とは別にDeployと試行開始の承認を見る。

### 条件が変われば使える点

- 確定した最小限の約束（例: 書いた内容をそのまま外部発信しない）は掲示してよい。

Anti-pattern名は、同じ失敗の再発防止に役立つ場合だけ付けます。

外部カタログを一括コピーせず、このRepositoryで実際に確認した失敗だけを蓄積します。

不採用事例を禁止事項の無制限な追加に使いません。
