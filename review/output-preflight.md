# Output Preflight V1

このチェックは、`Human Visual Acceptance` の後に、印刷または公開してよい状態かを確認するために使います。

見た目の採否と、出力条件の確認を分離します。

## 共通確認

- 仕上がりサイズが意図どおりか。
- 必須情報が欠けていないか。
- 誤字や古い文言が残っていないか。
- URLや連絡先が正しいか。
- QRコードを実機で読み取れるか。
- 重要な文字や図が端に寄りすぎていないか。
- 画像が粗く見えないか。
- フォント置換や文字化けが起きていないか。

## 印刷する場合

- 塗り足しが必要な印刷物では、印刷所の指定値を満たしているか。
- 断裁で失いたくない文字や図が安全域の内側にあるか。
- 画像解像度が印刷用途として不足していないか。
- 色指定やPDF形式に印刷所固有の条件がある場合、その条件を満たしているか。
- 可能なら実寸で1部確認したか。

印刷所ごとの指定がある場合は、その指定をこの共通チェックより優先します。

## 画面公開する場合

- 想定する画面幅で内容が欠けないか。
- リンク先が正しいか。
- 画像や文字が過度に重くないか。
- 公開してはいけない個人情報や内部情報が含まれていないか。

## 判定

- `PASS`: `Human Output GO` の判断へ進める。
- `PASS WITH CORRECTION`: 指摘箇所を修正して再確認する。
- `HOLD`: 出力条件が確認できないため、印刷または公開しない。

## Human Output GO

このチェックのPASSは、自動で印刷または公開してよいことを意味しません。

最終的に印刷または公開するかは、人が `Human Output GO` で決めます。

## 人に説明すると

デザインがよく見えても、QRが読めない、文字が切れる、印刷サイズが違うと実用品としては完成していません。

そのため、見た目のOKと、実際に出してよいかのOKを分けます。

`Human Visual Acceptance` は「この見た目でよいか」を決める確認です。

`Human Output GO` は「このファイルを実際に印刷または公開してよいか」を決める確認です。
