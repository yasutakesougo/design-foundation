# Colors V1

## 基本方針

深い緑を主軸にし、白または低彩度の明るい背景と組み合わせます。

色は意味と階層を補助するために使い、色だけで状態や重要度を伝えません。

## 推奨パレット

| Role | Value | Use |
| --- | --- | --- |
| Primary | `#234E3F` | 見出し、主要ボタン、主要な線 |
| Primary Soft | `#DDE9E3` | 面の区切り、淡い強調 |
| Text | `#1F2421` | 本文 |
| Muted Text | `#5F6863` | 補足 |
| Surface | `#FFFFFF` | 基本背景 |
| Surface Soft | `#F5F7F5` | セクション背景 |
| Border | `#D7DDD9` | 境界線 |
| Accent | `#B56F3D` | 限定的な注意・補助強調 |

Accentは面積を小さくし、ブランド主色として使いません。

## 運用ルール

同一画面や一面の中で、役割のない追加色を増やしません。

写真やイラストの色が強い場合は、UI側の色数を減らします。

デジタル表示では、文字と背景、操作に必要な非テキスト要素のコントラストを `accessibility.md` の基準で確認します。
