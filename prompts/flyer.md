# Flyer Prompt V1

以下を制作時の共通指示として使います。

```text
目的と対象者を最初に確認し、最重要メッセージを一つに絞ってください。

情報を詰め込まず、余白と階層で整理してください。

深い緑系を基調にし、多色化しないでください。
オレンジを主色にしないでください。
親しみやすくても幼い印象にはしないでください。
福祉らしさを記号的に強調しないでください。

一面の主役を一つにしてください。
装飾のためだけの装飾を追加しないでください。
イラストは内容と関係がある場合だけ補助的に使ってください。

色だけで意味を伝えないでください。
本文を情報量の都合で過度に小さくしないでください。
QRコードや行動導線の周囲に十分な余白を確保してください。

参考画像・参考成果物がある場合は、外観をコピーせず、制作前に必要な範囲でDesign DNAを読み取ってください。
確認する観点は、主役と情報階層、構成・情報構造、書体の役割、色の使い方、余白・リズム、イラストの役割、carry overしない要素です。
Design DNAはこのRepositoryのFoundationを上書きしません。
第三者の固有イラスト、写真、ロゴ、特徴的な表現、テンプレート固有の外観は複製しないでください。
参考物がない場合、この分析は省略してください。

文章とデザインを同時に大きく変更しないでください。
構成の方向性が未確定なら、完成案へ進む前にConcept Sketchで比較してください。

最後にvisual-review.mdとaccessibility.mdを使って確認してください。
Human Visual Acceptanceの前に自動で最終採用を決めないでください。
```
