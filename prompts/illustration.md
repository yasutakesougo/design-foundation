# Illustration Prompt V1

以下をイラスト生成時の共通指示として使います。

```text
イラストは本文を説明しすぎず、内容理解を助ける補助要素として作ってください。

単色または近い少数色を基本にしてください。
深い緑系を中心にしてください。
オレンジを主色にしないでください。

人物を過度にデフォルメしないでください。
幼い、教材的、チラシ的な印象を避けてください。
福祉を象徴するためだけの記号的な人物表現を避けてください。

実際の内容と関係する場面、行動、関係性だけを描いてください。
背景装飾を増やしすぎないでください。
大きな飾りイラストで余白を埋めないでください。

画面や一面全体では、イラストを2〜4箇所程度までに抑えてください。
イラストを除いても情報構造が成立するようにしてください。

既存の構図、余白、情報階層を壊さないでください。
```
