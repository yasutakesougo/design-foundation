# Color Selection Prompt V1

## 使う場面

既存のDesign Foundationを使って、Web、アプリ、チラシ、ポスター、広報資料の配色を決めるときに使います。

## Prompt

```text
対象制作物の配色を検討してください。

最初に `foundations/colors.md` と `foundations/accessibility.md` を正本として扱ってください。

案件固有のStyle Guideや既存ブランド色がある場合は、それも先に確認してください。

既存のPrimary、Text、Surface、Accentを理由なく変更しないでください。

最初に、新しい色を追加する必要があるかを判断してください。

追加が不要なら、正本パレット内だけで構成してください。

追加が必要なら、各候補について次を示してください。

- 用途: background / surface / text / primary / accent / semantic
- 候補値
- 既存色との関係
- 想定する使用面積
- 追加が必要な理由

参考画像を使う場合は、抽出した色と推定した色を区別してください。

外部配色ツールを使う場合は、結果を候補として扱い、自動採用しないでください。

初稿では Neutral を最も広く、Primaryを限定し、Accentをさらに小さくしてください。

開始点の目安として Neutral 80 / Primary 15 / Accent 5 を使えますが、固定比率として扱わないでください。

パレットだけを並べて評価せず、実際の文字、背景、面、画像、CTAへ割り当てて確認してください。

色だけで状態、重要度、可否を伝えないでください。

デジタル表示ではコントラスト基準を確認してください。

印刷物では数値だけで合格にせず、実寸Human Reviewを残してください。

最後に、次の形式で結果を返してください。

1. 維持する正本色
2. 追加候補がある場合だけ候補一覧
3. 役割別の使用案
4. コントラストと色依存の確認結果
5. Human Reviewで見る点
6. 採用 / 保留 / 不採用の提案

Foundationへの昇格とHuman Visual Acceptanceは自動決定しないでください。
```
